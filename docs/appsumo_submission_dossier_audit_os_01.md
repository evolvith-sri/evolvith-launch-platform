2. **Is AUDIT-OS-01 an AI prompt list, ChatGPT wrapper, or generic Chrome extension?**  
   `No. AUDIT-OS-01 is a deterministic software operating system and visual workstation built with TypeScript and Python. It contains mathematical AST schema inference algorithms, real cryptographic HMAC verification engines, and local-first replay harnesses.`
3. **Does AUDIT-OS-01 require a recurring monthly or annual subscription?**  
   `No. This AppSumo deal grants a one-time perpetual commercial license. There are no per-seat fees, recurring cloud charges, or metered execution penalties for internal team use within your purchasing organization.`
4. **Where does the software run and who owns my payload data?**  
   `AUDIT-OS-01 is built around local-first developer workflows. Core QA operations (AST diffing, code generation, mock exporting, HMAC testing, and Python CLI runs) execute locally in your browser or local environment. Ephemeral public webhook traps temporarily relay test events through stateless edge endpoints without permanent cloud storage.`
5. **How does the Visual AST Schema Diff engine detect breaking changes?**  
   `The engine parses baseline and incoming JSON payloads into Abstract Syntax Trees (AST). It mathematically evaluates structural mutations across 6 critical failure modes: Field Removals, Type Mutations (e.g. string to number), Nullability Violations, Numeric Widening, Missing Required Keys, and Array Tuple Mismatches. Each mutation is tagged with its exact JSONPath.`
6. **What programming languages and schema formats are supported for code generation?**  
   `AUDIT-OS-01 currently generates three production-grade formats in one click: TypeScript Interfaces, Zod Validation Schemas, and Python Pydantic v2 Models (BaseModel with typed fields and Optional typing).`
7. **How does the Localhost Replay Studio work?**  
   `The Replay Studio takes any captured webhook payload and re-transmits it via HTTP POST/PUT to your local development server (e.g. http://localhost:3000/api/webhooks). You can override headers and step through your local webhook handler line-by-line using your local debugger. It includes a safety confirmation check to prevent accidental replay to live remote servers.`
